Usage from the project root:
  .\FORMAT.ps1                Format game Lua sources with AST verification.
  .\FORMAT.ps1 -Check         Check formatting without writing source files.
  .\FORMAT.ps1 -Target game/src/app   Format a selected source directory.

The upstream AST verification option is --verify (not --verifyAST).
Formatting verifies syntax/AST similarity; it does not replace gameplay tests.
See https://github.com/JohnnyMorganz/StyLua/blob/v2.6.0/README.md#--verify-verifying-formatting-output
